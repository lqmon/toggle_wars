What's inside

      
Everything after docker compose up

      
Starting Flagsmith is one command. Getting to a working A/B test took an afternoon of reading Django source. FlagKit is that afternoon, automated.

      

        

          

          
flagkit up: zero-click bootstrap

          
Official Flagsmith images, then admin, org, project and three environments, an admin API key, and the experimentation warehouse, all through the API. Bound to localhost, random secrets, sign-up locked. Writes a flagsmith.env the official CLI understands.

        

        

          

          
flagkit doctor

          
Points at any self-hosted Flagsmith and finds silent breakage, then fixes it after asking.

        

        

          

          
flagkit tui

          
Every flag × every environment in your terminal, plus live win probabilities and a guarded “ship the winner”.

        

        

          

          
Agent Skill

          
A coding agent goes from hypothesis to rollout to cleanup PR with the Flagsmith CLI, stopping at 5 approval gates.

        

        

          

          
MCP server

          
Agents can inspect flags, read results and propose rollouts. A person approves before anything changes.
